# 数据管道兜底方案 v1.0

## 问题现状

2026-08-09 数据审计结果：
| 指标 | 数值 |
|------|------|
| 总缓存文件 | 31个 |
| WebSearch 成功率 | **16% (5/31)** |
| 26场全部返回0结果 | 83% |
| engine标记为空 | 26场未找到搜索引擎 |

**根因分析**：
- 单独调用 `cn_bing` 引擎时正常（圣保利/纽伦堡各返回5条）
- 批量执行时大量任务 `search_engine_used: ""`，说明未进入搜索引擎选择逻辑
- 疑似并发执行中的异常吞噬或状态传递bug

## 三层兜底方案

```
Layer 1: 批量情报采集（优先，已有）
  ├── 新浪竞彩大势 / 搜狐 / 网易 / 足彩网 / SOHU
  ├── 多源交叉验证 → 高置信度
  └── 覆盖：约60-70%场次

Layer 2: The Odds API 赔率兜底（需扩展）  
  ├── 40+联赛覆盖，22家bookmaker
  ├── 即使无情报，有赔率就能做：
  │   ├── DOIT公式 → 倒三角信号
  │   ├── 凯利指数 → 价值判断
  │   ├── 欧亚转换 → 盘口合理性
  │   └── 多公司赔率共识 → 信用评级
  └── 覆盖：约80-90%场次

Layer 3: 纯赔率分析（最后兜底）
  ├── 仅需主胜/平局/客胜三赔率
  ├── DOIT + 凯利 + 返还率计算
  ├── 不依赖H2H/伤停/PFI/天气
  └── 覆盖：只要有开盘的市场
```

## 数据质量分级标签

每场比赛标注数据源级别：

| 标签 | 含义 | 数据源 | 最高星级 | 示例 |
|------|------|--------|----------|------|
| 🟢 AAA | 完整情报+实时赔率 | 批量+API+WebSearch | ⭐⭐⭐⭐⭐ | 圣保利vs菲尔特 |
| 🟡 AA | 批量情报+部分赔率 | 批量+部分API | ⭐⭐⭐⭐ | 哈马比vs赫根 |
| 🟠 A | 仅有批量情报 | 新浪/搜狐等 | ⭐⭐⭐ | 克里斯蒂安松vs莫尔德 |
| 🔴 B | 仅有赔率 | The Odds API | ⭐⭐⭐ | 本菲卡vs维塞乌(如API覆盖) |
| ⚪ C | 完全无数据 | 无 | ⭐ 不推荐 | 当前本菲卡状态 |

## 对比赛分析的影响

### 🟢 AAA级（当前: 2场）
- 准7步分析，高信心
- 圣保利vs菲尔特、纽伦堡vs德累斯顿

### 🟡 AA级（当前: 约15场）
- 批量情报提供基本面+赔率分析
- 哈马比vs赫根、天狼星等瑞典超场次

### 🟠 A级（当前: 约5场）
- 仅有批量数据，无实时赔率
- 需标记"数据置信度中等"

### 🔴 B级（当前: 0场，待API扩展）
- 如果The Odds API能覆盖本菲卡
- 可以做DOIT+凯利分析
- 标记"纯赔率分析，无情报支持"

### ⚪ C级（当前: 26场-已由批采填补部分）
- 完全不可分析
- 强烈不建议投注
