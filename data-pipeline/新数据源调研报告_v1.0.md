# 三轮管道新数据源可用性调研报告 v1.0

> 调研日期：2026-08-10 | 目标：评估12个候选数据源的可访问性与集成价值

---

## 一、现有管道数据源回顾

当前三轮管道（数据采集→交叉验证→分析报告）依赖以下数据源：

| 序号 | 数据源 | 接入方式 | 覆盖层 | 状态 |
|------|--------|---------|--------|------|
| 1 | 竞彩官方 (sporttery.cn) | jc-mcp MCP 本地服务器 | Layer 3 赔率 | ✅ 稳定 |
| 2 | 500.com | WebFetch | Layer 3 赔率 + 百家欧指 | ✅ 稳定 |
| 3 | The Odds API | REST API (已有Key) | Layer 3 国际赔率 | ✅ 稳定 |
| 4 | Open-Meteo | REST API (免费) | Layer 5 天气 | ✅ 稳定 |
| 5 | WebSearch 14词模板 | WebSearch | Layer 1-6 全层 | ✅ 稳定 |

**缺口分析**：
- 缺少中文赛事深度数据源（伤停精确到人、阵容预测）
- 缺少亚洲博彩公司赔率对比（仅竞彩+Bet365+Pinnacle）
- 缺少免费API级别的结构化情报数据
- 缺少多源预测交叉验证的第三方预测参考

## 五、建议实施方案
