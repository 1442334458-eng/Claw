# 竞彩足球全流程分析 v8.0

## 触发条件
用户发送竞彩截图时触发。必须严格按照此流程执行，不得跳过任何步骤。

## 角色分工（单 Agent 顺序执行，确保不遗漏）

本 Skill 采用"三猿模式"分阶段执行，每个阶段完成后 CHECKPOINT 确认。

---

## Phase 1: 情报猿 - 数据收集

### Step 1.1: 解析截图
- 读取用户发送的所有竞彩截图
- 提取所有场次的：编号、联赛、主队、客队、开球时间、初盘赔率（胜/平/负）、让球盘

### Step 1.2: 调用数据管道
- 按联赛分组，调用 main.py 拉取数据：
  ```
  python main.py --matches "主队 vs 客队, ..." --league "联赛名" --city "城市"
  ```
- 对每个联赛单独调用（避免跨联赛 sport_key 冲突）
- 等待所有 API + WebSearch 任务完成

### Step 1.3: 生成数据清单表格
输出格式：
```
| 编号 | 联赛 | 主队 vs 客队 | 时间 | 主胜 | 平局 | 客胜 | 让球 | API状态 |
|------|------|------------|------|------|------|------|------|---------|
```
标记每个场次的 API 数据状态（完整/部分/无数据）

### CHECKPOINT 1: 确认数据收集完成，进入 Phase 2

---

## Phase 2: 分析猿 - 筛选与深度分析

### Step 2.1: DOIT 初筛（所有场次）
对每场比赛计算：
```
theoretical = √(home_odd × away_odd)
ratio = theoretical / draw_odd
```
- ratio < 0.88 → 平局偏厚，触发 DOIT 异常信号
- 标记所有触发异常的场次

### Step 2.2: 铁律 v7.5.2.7 通过性检查
对 DOIT 异常场次，逐一过 29 条铁律：
- 规则 1-5: 赔率结构类
- 规则 6-12: 盘口变动类
- 规则 13-18: 球队基本面类
- 规则 19-23: 情报信号类
- 规则 24-26: 反常信号类
- 规则 27: 亚盘异动（单独）
- 规则 28: PFI 疲劳度
- 规则 29: 首发暴露

### Step 2.3: 星级评分
- 每通过 1 条铁律 = +0.25 星
- DOIT 信号 + 1 星
- 赔率共识（多公司一致）+ 0.5 星
- 基本面明显占优 + 0.5 星
- 最高 5 星

### Step 2.4: 深度 7 步分析（≥4 星场次）
对每场高星级比赛执行：
1. 基本面：积分/排名/近5场/主客场对比
2. 赔率面：多公司共识/欧亚转换/凯利指数
3. H2H：历史交锋/心理优势
4. PFI：休息天数/旅行距离/一周双赛
5. 天气：温度/湿度/风速对比赛影响
6. 新闻动因：升级/保级/德比/复仇
7. 首发阵容：泄露/伤病/主力缺阵

### CHECKPOINT 2: 确认分析完成，输出星级排序
