# 足球竞彩投注分析技能

## 触发条件

当用户询问以下内容时加载此技能：
- 足球投注方案、推荐、分析
- 竞彩足球、串关、单关
- 世界杯、欧冠、五大联赛比赛预测
- 胜平负、让球胜平负、半全场、比分玩法
- 赔率分析、盘口解读
- 投注复盘、中奖记录

## 用户偏好档案

### 基本偏好
- **沟通语言**：中文简短回复，拒绝冗余
- **输出格式**：表格展示赔率和方案，星级标注置信度
- **决策风格**：快速决策，A/B方案确认后执行
- **验证方式**：偏好截图调试，用实际结果质疑预测要求重新分析

### 投注风格
- **重点关注**：2026世界杯 L/K/J 组串关投注
- **核心玩法**：让球胜平负（让胜/让负）、**半全场**、**比分预测**
- **分析依据**：战力、战意、前两场成绩、小组排名对淘汰赛对阵的影响
- **路径**：基本选项 → 深入分析 → 变体方案（渐进式）

### 联赛优先级（由高到低）
1. **世界杯/欧洲杯/亚洲杯** — 大赛优先，信息充足
2. **英超/西甲/德甲/意甲/法甲** — 五大联赛，数据完善
3. **中超/日职/JK联赛** — 亚洲主流联赛
4. **巴甲/墨超/阿甲** — 南美联赛，降低仓位
5. **其他小联赛** — 仅作为补位，高风险高警惕

## 团队架构（四猿分工）

> 批量分析必须使用 `football-analysis-squad` 团队并行协作，不可单人串行。

## 分析流程

### 第一步：信息收集
1. 确认赛事、对阵双方、开赛时间
2. 获取最新赔率数据（使用 westock-data 或 neodata-financial-search）
3. 查询两队近期战绩（前2-5场）、历史交锋
4. 了解战意情况（出线形势、争冠/保级需求、轮换可能）

### 第二步：基础分析（必做）
对每场比赛输出以下维度：

| 维度 | 说明 |
|------|------|
| 战力对比 | 阵容实力、核心球员状态、伤病情况 |
| 近期走势 | 近3场战绩、进球/失球趋势 |
| 战意评估 | 出线/排名动力、轮换可能性 |
| 盘口解读 | 让球方合理性、水位变化 |

### 第三步：方案输出规范

#### 方案结构（严格遵循）

```
【主推方案】⭐⭐⭐⭐⭐ (最高信心)
├─ 场次1：XX vs XX | 投选项 | 赔率 | ★★★★★
├─ 场次2：XX vs XX | 投选项 | 赔率 | ★★★★☆
└─ 场次3：XX vs XX | 投选项 | 赔率 | ★★★★☆
→ 组合方式：X串1 / X倍 / 本金XX元 / 预计回报XX元

【稳妥备选】⭐⭐⭐⭐ (保守选择)
├─ ...（同上格式）
→ 特点：低赔率、高命中率、适合保本金

【博冷方案】⭐⭐⭐ (高风险高回报)
├─ ...（同上格式）
→ 特点：含冷门项、命中率低但回报极高
→ ⚠️ 风险提示：此方案适合小仓位尝试
```

#### 星级置信度标准

| 星级 | 含义 | 建议 |
|------|------|------|
| ★★★★★ | 高度确信 | 可作为主推核心 |
| ★★★★☆ | 较有把握 | 主推方案的组成部分 |
| ★★★★☆ | 有一定把握 | 备选方案可用 |
| ★★★☆☆ | 五五开 | 需配合其他高信心场次 |
| ★★☆☆☆ | 博弈性 | 仅出现在博冷方案 |
| ★☆☆☆☆ | 不推荐 | 明确标注不投 |

### 第三步半：比分预测与半全场专项分析（核心玩法）

#### 3A. 比分预测方法论

**分析框架（6维度）：**

| 维度 | 分析内容 | 数据来源 |
|------|---------|---------|
| **进攻火力** | 近5场场均进球、射正率、预期进球(xG) | 战绩数据 |
| **防守硬度** | 近5场场均失球、零封次数、后防伤停 | 战报/阵容 |
| **交锋历史** | 历史对阵常见比分区间 | H2H数据 |
| **联赛特征** | 该联赛平均进球数（高/低比分联赛） | 联赛统计 |
| **战意节奏** | 抢开局 vs 稳守反击？影响进球时间分布 | 赛况分析 |
| **关键球员** | 头号射手状态、主力门将表现 | 阵容信息 |

**比分预测输出格式：**

```
XX vs XX — 预测比分
├─ 主推比分：X:X (赔率 X.XX) ★★★★☆
├─ 备选1：   X:X (赔率 X.XX) ★★★☆☆
├─ 备选2：   X:X (赔率 X.XX) ★★★☆☆
├─ 进球数预判：2-3球 (大2.5球 / 小2.5球)
└─ 比分逻辑：[一句话说明依据]
```

**常用比分区间参考：**

| 场景类型 | 常见比分 | 出现频率 |
|---------|---------|---------|
| 强队主场碾压弱旅 | 2:0 / 3:0 / 3:1 | 高 |
| 实力接近的较量 | 1:1 / 1:0 / 2:1 | 中高 |
| 大赛关键战（保守） | 1:0 / 1:1 / 0:0 | 中 |
| 南美联赛（攻强守弱） | 2:1 / 3:2 / 2:2 | 偏高 |
| 德比战（胶着） | 1:0 / 1:1 / 0:0 | 偏高 |

**⚠️ 比分玩法注意事项：**
- 单场命中率极低（通常 <15%），必须搭配稳胆做串关
- 建议每场比赛选 **1-2个主推比分 + 1个备选**，不超过3个
- 世界杯/大赛可适当增加比分投注比重（战术更明确）
- 小联赛比分波动极大，不建议作为比分玩法主力

#### 3B. 半全场分析方法论

**半全场 = 上半场结果 + 全场结果的组合，共9种选项**

| 组合类型 | 含义 | 典型场景 | 风险等级 |
|---------|------|---------|---------|
| **胜/胜** | 上半领先+全场赢 | 强队主场早早确立优势 | 低 |
| **平/胜** | 上半平局+全场赢 | 强队慢热但实力碾压 | 低中 |
| **负/负** | 上半落后+全场输 | 弱队客场全面被动 | 低 |
| **平/平** | 上半平+全场平 | 势均力敌+保守对峙 | 中 |
| **胜/平** | 上半领先+被追平 | 领先方松懈/对手顽强 | 中高 |
| **平/负** | 上半平+客场逆转 | 冷门！高回报 | 高 |
| **负/胜** | 上半落后+逆转翻盘 | 大逆转剧情 | 极高 |
| **负/平** | 上半落后+追平 | 追分能力体现 | 中高 |
| **胜/负** | 上半领先+被逆转 | 崩盘型冷门 | 极高 |

**半全场分析流程：**

```
Step 1: 判断全场方向（胜/平/负）
        ↓ 用基础分析四维度确定
Step 2: 判断上半场走势
        ├─ 查两队近5场上半场战绩
        ├─ 是否抢开局型球队？
        └─ 有无上半场进球/失球习惯
Step 3: 组合半全场
        ↓ 全场方向 + 上半场走势 → 锁定1-2个组合
Step 4: 赔率筛选
        ↓ 优先选择赔率合理(>2.00)的高价值组合
```

**半全场输出格式：**

```
XX vs XX — 半全场分析
├─ 全场判断：XX (★★★★☆)
├─ 上半场判断：XX (★★★☆☆)
│
├─ 【主推】X/X (赔率 X.XX) ★★★★☆
│   逻辑：[说明为什么是这个组合]
│
├─ 【备选】X/X (赔率 X.XX) ★★★☆☆
│   适用：如果出现[某种情况]
│
└─ 进球节奏预判：
    - 前15分钟：有/无进球可能
    - 45分钟前预计比分：?:?
    - 全场预计总进球：X-X球
```

**半全场黄金组合（经验总结）：**

| 组合 | 最佳适用场景 | 历史命中率参考 |
|------|-------------|--------------|
| **胜/胜** | 五大联赛主场让1.5球以上的强队 | ~35% |
| **平/胜** | 强客让球但习惯后半程发力 | ~20% |
| **平/负** | 大赛强队客场 + 对手主场不弱 | ~12%（高赔6-8倍） |
| **负/负** | 明显实力差距的客弱队 | ~30% |
| **胜/平** | 领先后易松懈的球队（如某些南美队） | ~8% |

#### 3C. 方案输出中的比分/半全场整合

在方案表格中加入额外列：

| 场次 | 赛事 | 对阵 | SPF投注 | 半全场(推荐) | 比分(主推) | 信心 |
|------|------|------|---------|------------|-----------|------|
| 6103 | 世界杯 | 法国vs英格兰 | 让负1.87 | 平/负(6.xx) | 1:1 / 1:2 | ★★★★☆ |

**组合策略建议：**

| 策略 | 做法 | 适用场景 |
|------|------|---------|
| **纯SPF串** | 只用胜平负/让球 | 追求稳定命中 |
| **SPF+半全场混串** | 稳胆用SPF，博值用半全场 | 提升整体回报 |
| **全半全场串** | 全部用半全场 | 昨天中奖模式，高风险高回报 |
| **比分单关** | 比分单独投注不串 | 博特定比分，娱乐性为主 |

### 第四步：变体方案生成（按需）
用户确认A/B主方案后，可追加：
- **容错版**：N串M（如3串4），允许1场失误
- **加倍版**：增加倍数的高信心单子
- **冷门版**：替换1个场次为冷门选项

### Step 2: Agent WebSearch 执行 + 外源兜底

### Step 2.5: 多源赔率交叉验证（🆕v1.5.1 — 消除单源盲区）

> **触发条件**：管道返回赔率数据后自动执行。不可跳过。
> **目的**：竞彩赔率返奖率仅71%，单源分析存在结构性盲区。多源交叉验证确保不被单一赔率误导。

#### 数据源架构

```
┌─ 竞彩官方 (sporttery.cn) ──── 官方出票赔率，返奖率~71%

└─ TheOddsAPI (Bet365/Pinnacle)  国际赔率，返奖率~96%

         ▼

```

#### 共识等级与星级联动

| 共识等级 | CV阈值 | 含义 | 星级调整 | 强制动作 |
|:--------:|--------|------|:--------:|---------|
| ✅ **高共识** | CV < 2% | 多源赔率一致，信号稳定 | **+0.5星** | 无额外要求 |
| 🟡 **中共识** | CV 2-4% | 基本一致，微调差距 | **不变** | 标注主要来源 |
| 🟠 **低共识** | CV 4-8% | 存在分歧，信号模糊 | **-1星** | 标注分歧原因 |
| 🔴 **分歧** | CV > 8% | 严重不一致，隐藏风险 | **-2星** | 强制双选 + 含冷 |
| ⚪ **单源** | — | 仅一个数据源 | **-1星** | 标注数据盲区 |

#### DOIT 多源增强

```
传统DOIT（单源）:
  DOIT = √(主胜赔 × 客胜赔) / 平赔

多源DOIT（增强版）:
  DOIT_mean = mean(DOIT_竞彩, DOIT_bet365, DOIT_william, ...)
  DOIT_std  = 平赔在各博彩公司间的分歧
  
触发条件（比单源更严）:
  DOIT_mean < 0.82  → 🔴 强警告（Rule 37 升级版）
  DOIT_mean < 0.88  → 🟠 DOIT触发
  DOIT_mean < 0.92  → 🟡 关注
  DOIT_std > 0.05   → ⚠️  平赔分歧大（不同庄家对平局看法不一）
```

#### 异常检测

自动检测任何数据源偏离均值超过 2 个标准差的赔率项：

```
示例：
  竞彩平赔 4.55 vs 多源均值 3.92 → 偏离 2.3σ → 🚨 竞彩平赔异常偏高
  → 解读：竞彩平赔结构性偏厚，实际平局概率可能高于竞彩隐含值
  → 动作：含平选项，DOIT手动向下修正
```

### DOIT首轮估算模式（🆕v1.5.0）

> **问题**：首轮比赛DOIT无历史数据，导致像本菲卡2-2这样的冷门无法被DOIT弱信号捕捉。
> **解决方案**：使用替代数据估算首轮DOIT。

```
估算方法（按优先级）：
1. 上赛季末尾10场的拉平数据 → 作为首轮代理值
2. 相似配置球队的类比（同级别联赛+相似排名+相似阵容深度）
3. 仅上赛季H2H数据（如果两队上赛季交手过）

估算标记：⭐(E) → 表示这是"估算DOIT"，权重按实际DOIT的60%计算

应用示例：
  本菲卡 vs 维塞乌(升班马)：
  → 维塞乌为升班马，无从估算
  → 替代方法：用葡超上季末3名下赛季首轮平均DOIT(约0.72)
  → DOIT估算 < 0.80 → Rule 37触发 → 必须含平
  → 实际2:2 → 完美覆盖！
```
