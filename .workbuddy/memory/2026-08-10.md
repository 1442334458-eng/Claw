## FotMob 数据采集器构建 (P0 Phase 1 最后一项)

### 调研
- FotMob API 端点: `www.fotmob.com/api/` (unversioned, 无需认证)
  - `/api/matchDetails?matchId={id}` — 核心端点，完整比赛详情
  - `/api/matches?date=YYYYMMDD` — 按日期获取比赛列表
  - `/api/searchData?term={query}` — 搜索球队/球员/比赛
  - `/api/teams?id={id}` — 球队数据
  - `/api/playerData?id={id}` — 球员数据
- 沙箱环境直连被封锁 (返回HTML 404)，需通过 CodeBuddy WebFetch 调度器访问
- 参考: pseudo-r/Public-FotMob-API (MIT开源文档)

### 实施
**fotmob_collector.py** — 723行，v1.0

数据模型 (9个dataclass):
- FotMobTeamStats: xG/控球/射门/传球/抢断/角球/绝佳机会等15+字段
- FotMobPlayerRating: 球员评分(xG/xA/评分/射门/传球)
- FotMobLineup: 阵容+阵型+教练+平均评分
- FotMobShotMap: 射门坐标+xG+xGOT+类型
- FotMobMomentum: 分钟级势头数据
- FotMobH2H/GoalEvent: 历史交锋/进球事件
- FotMobMatchReport: 完整比赛报告 (聚合以上所有)

核心功能:
- 任务生成: match_detail / match_list / search / match_id_discovery
- JSON全自动解析: parse_match_detail() / parse_match_list()
- 管道格式转换: to_pipeline_format() 输出统一格式
- 信号提取: xG偏离/阵容评分/控球对比/射门效率/阵型分析
- 风险评估: 基于xG/评分/红牌的综合风险
- 联赛ID映射: 20+主流联赛 FotMob ID

管道覆盖:
- Layer 1: 阵容+阵型+球员评分
- Layer 2: xG/xA (填补最大空白) + 控球/射门/传球50+统计
- Layer 3: H2H历史交锋
- Layer 6: 比赛势头+进球事件

与球迷屋采集器的关系:
- 球迷屋: 中文伤停(精确到人) + H2H + 前瞻 → 互补不重复
- FotMob: xG数据 + 球员评分 + 射门图 → 填补数据空白

### DOIT修复 (cross_validate.py v1.1)
**问题**: DOIT公式 `1/draw - 1/home` 对深盘主队产生负值（-0.67），被noise阈值掩盖

**修复**:
1. DOIT公式改为 `|1/Draw - 1/Home|` → 取绝对值，正确表示平局与主胜的隐含概率差距
2. 竞彩DOIT独立计算 → 不参与多源均值，作为独立主信号源
3. P1/P2防平可抵消"多源高度共识"的正向星级加成
4. 建议输出优先显示竞彩DOIT信号

**修复后对比**:
  - 1001: DOIT -0.65→0.65 (moderate) + 竞彩0.668(P1) → 强烈建议双选
